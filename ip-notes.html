1. Pandas — Series

Definition: A Series is a one-dimensional labelled data structure in Pandas.

Meaning: It stores values with an associated index, making data selection and analysis easier.

Full Form: IP = Informatics Practices.

2. Pandas — DataFrame

Definition: A DataFrame is a two-dimensional labelled tabular data structure.

  • Rows and columns can contain labelled data.
  • Common operations include selection, filtering, sorting, adding and deleting columns.

3. Data Handling & Analysis

Data handling means cleaning, organising and transforming data so that useful information can be obtained.

  • Filtering selects rows meeting a condition.
  • Sorting arranges data according to a column.
  • Missing data should be identified and handled appropriately.

4. Data Visualization

Visualization represents data graphically so patterns and comparisons are easier to understand.

  • Line chart — trends over time.
  • Bar chart — comparison of categories.
  • Histogram — distribution of numerical data.

Library: Matplotlib is commonly used for plotting in Python.

5. SQL — Basics

SQL = Structured Query Language. It is used to work with relational databases.

  • SELECT retrieves data.
  • WHERE filters records.
  • ORDER BY sorts results.
  • GROUP BY groups rows.
  • COUNT, SUM, AVG, MIN, MAX are common aggregate functions.

6. Database Concepts

DB = Database. A database is an organised collection of data.

DBMS = Database Management System. RDBMS = Relational Database Management System.

A table contains rows (records) and columns (fields/attributes). A primary key uniquely identifies records.

7. Computer Networks

  • LAN = Local Area Network — small geographic area.
  • MAN = Metropolitan Area Network — city-scale network.
  • WAN = Wide Area Network — large geographic area.

Network devices such as switches, routers and access points help connect and manage networks.

8. Internet & Web

URL = Uniform Resource Locator. HTTP = Hypertext Transfer Protocol. HTTPS = Hypertext Transfer Protocol Secure.

HTML = HyperText Markup Language. It structures content on web pages.

9. Cyber Safety & Ethics

Cyber safety means protecting devices, accounts and data from misuse.

  • Use strong unique passwords and protect login information.
  • Be cautious with suspicious links and messages.
  • Respect privacy, intellectual property and digital rights.
  • Maintain backups of important data.
