1. Pandas — Series

Series is a one-dimensional labelled data structure in Pandas. Values are associated with an index.

Important Operations

  • Create Series from list, dictionary or scalar.
  • Access by labels/positions.
  • Perform arithmetic and filtering.
  • Inspect index and values.
import pandas as pd
s = pd.Series([10,20,30], index=['a','b','c'])
print(s['b'])
Q1. What is a Series?
A. A one-dimensional labelled Pandas data structure.
Q2. What is an index?
A. Labels used to identify and access elements in a Series or rows in a DataFrame.

2. Pandas — DataFrame

A DataFrame is a two-dimensional labelled tabular data structure consisting of rows and columns.

Operations

  • Create from dictionary/list.
  • Select columns and rows.
  • Add/delete/rename columns.
  • Filter and sort data.
  • Handle missing values.
df = pd.DataFrame({'Name':['A','B'],'Marks':[80,90]})
print(df['Marks'])
print(df[df['Marks'] > 80])
Q1. Series vs DataFrame?
A. Series is one-dimensional; DataFrame is two-dimensional and tabular.
Q2. How do you select a column?
A. Use df['ColumnName'] or an equivalent labelled selection method.

3. Data Handling & Analysis

Data handling means cleaning, organising, transforming and analysing data to obtain useful information.

Key Operations

  • Filtering rows using conditions.
  • Sorting by one or more columns.
  • Detecting missing values.
  • Filling or removing missing values appropriately.
  • Grouping and summarising data.
Q1. What is filtering?
A. Selecting records that satisfy a specified condition.
Q2. Why handle missing values?
A. Missing values can affect calculations, analysis and visualisation, so they should be handled appropriately.

4. Data Visualization

Visualization presents data graphically so trends, distributions and comparisons are easier to understand. Matplotlib is commonly used with Python.

  • Line chart — trends over an ordered sequence/time.
  • Bar chart — comparison of categories.
  • Histogram — distribution of numerical data.
import matplotlib.pyplot as plt
plt.plot([1,2,3],[10,20,15])
plt.xlabel('X')
plt.ylabel('Y')
plt.show()
Q1. Which chart is suitable for category comparison?
A. Bar chart.
Q2. Which chart shows distribution?
A. Histogram.

5. SQL — Basics

SQL means Structured Query Language. It is used to create, retrieve, update and manage data in relational databases.

Important Commands

  • SELECT — retrieve data.
  • WHERE — filter rows.
  • ORDER BY — sort results.
  • GROUP BY — group rows.
  • HAVING — filter groups.
  • INSERT — add records.
  • UPDATE — modify records.
  • DELETE — remove records.

Functions

COUNT, SUM, AVG, MIN and MAX.

SELECT Name, Marks FROM Student WHERE Marks > 80 ORDER BY Marks DESC;
Q1. What is SQL?
A. Structured Query Language used to work with relational databases.
Q2. WHERE vs HAVING?
A. WHERE filters rows before grouping; HAVING filters groups after GROUP BY.
Q3. Write a query to show all students with marks above 90.
A. SELECT * FROM Student WHERE Marks > 90;

6. Database Concepts

DB = Database. DBMS = Database Management System. RDBMS = Relational Database Management System.

A table contains rows/records and columns/fields. A primary key uniquely identifies records.

Q1. What is a database?
A. An organised collection of related data that can be stored and accessed systematically.
Q2. What is a primary key?
A. A field or set of fields that uniquely identifies each record in a table.
Q3. DBMS vs RDBMS?
A. DBMS manages databases generally; RDBMS manages related tables using relational concepts and keys.

7. Computer Networks

A computer network connects devices so that they can communicate and share resources.

  • LAN — Local Area Network, small area.
  • MAN — Metropolitan Area Network, city-scale.
  • WAN — Wide Area Network, large geographic area.
  • Router — connects networks and forwards packets.
  • Switch — connects devices within a network.
  • Access point — provides wireless network access.
Q1. LAN vs WAN?
A. LAN covers a relatively small area; WAN connects networks across large geographical areas.
Q2. What does a router do?
A. It forwards data packets between networks.

8. Internet & Web

URL = Uniform Resource Locator. HTTP = Hypertext Transfer Protocol. HTTPS = Hypertext Transfer Protocol Secure. HTML = HyperText Markup Language.

Q1. HTTP vs HTTPS?
A. HTTPS adds encryption and authentication mechanisms through TLS to protect web communication.
Q2. What is HTML?
A. A markup language used to structure content on web pages.
Q3. What is a URL?
A. The address used to locate a resource on the web.

9. Cyber Safety & Ethics

Cyber safety means protecting devices, accounts, networks and data from misuse. Ethical digital behaviour respects privacy, intellectual property and rights.

  • Use strong unique passwords.
  • Enable multi-factor authentication where available.
  • Do not share OTPs or passwords.
  • Be cautious with suspicious links and attachments.
  • Keep software updated and maintain backups.
  • Respect copyright and privacy.
Q1. What is phishing?
A. A deceptive attempt to obtain sensitive information by pretending to be a trustworthy person or service.
Q2. Why use strong passwords?
A. Strong unique passwords reduce the chance that an account can be accessed through guessing or reused leaked credentials.
